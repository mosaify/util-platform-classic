= util-platform-classic - Kotlin Multiplatform

Basic platform utils to use with Kotlin Multiplatform projects.

== Supported platforms

JS (browser, NodeJS), JVM, linuxX64, macosArm64, mingwX64.

== Using the library

[source,kotlin]
----
// ...

dependencies {
    implementation("dev.mosaify:util-platform-classic:1.0.0")
}
----
